Teknologi Observatorium Modern

HILTRON menghubungkan tradisi keilmuan hisab rukyat Islam dengan terobosan komputasi antariksa presisi dan teknologi otomasi modern.

Ephemeris Presisi Tinggi NASA JPL DE421

Mengintegrasikan kernel SPICE NASA JPL DE421 melalui pustaka Python Skyfield untuk kalkulasi koordinat geosentrik dan toposentrik Matahari dan Bulan dengan akurasi sub-detik busur.

  • Waktu Ghurub (Sunset), Ijtima' (Konjungsi), dan GMST presisi tinggi.
  • Evaluasi otomatis Kriteria MABIMS 2021 (Tinggi Hilal ≥ 3°, Elongasi ≥ 6.4°).
  • Konversi otomatis Kalender Hijriah Umm al-Qura.

Peta Visibilitas Global Biner (Geobuf)

Visualisasi spasial keterlihatan hilal seluruh dunia berbasis big data spasial yang dikompresi ke dalam format Protocol Buffers biner (Geobuf/PBF) untuk rendering instan tanpa jeda jaringan.

  • Kompresi biner Geobuf 80% lebih ringan daripada GeoJSON standar.
  • Pemetaan zona MABIMS, Imkanur Rukyat, dan Wujudul Hilal global.
  • Pembaruan dinamis berbasis koordinat toposentrik per menit.

Visualisasi 3D Digital Twin Ganda

Simulasi 3D fotorealistik berbasis Three.js dengan pencahayaan fisis: Earth Globe untuk perspektif kosmik luar angkasa dan Skydome Ufuk Barat untuk simulasi pandang pengamat rukyat.

  • Custom GLSL Sky Shader (Rayleigh scattering, golden hour, langit malam).
  • Tekstur bola bumi NASA dengan pendaran atmosfer fisis & pencahayaan matahari.
  • Render fase bulan dinamis dan posisi hilal di atas garis ufuk.

Autonomous Hardware Tracker (ESP32 IoT)

Perangkat keras pengendali teleskop sumbu ganda (*Azimuth & Altitude*) menggunakan mikrokontroler ESP32, motor stepper dengan micro-stepping, sensor kompas/tilt Bosch BNO055, dan GPS NEO-6M.

  • Celestial Live Lock: Kompensasi rotasi bumi secara kontinu (~14.5°/jam).
  • Shortest Path Angle Wrapping: Gerakan rotasi azimuth terpendek (-180° s/d +180°).
  • Dual-Protocol: WebSocket LAN lokal kencang & Cloud MQTT via EMQX.
Hardware Engineering

Arsitektur Robotik Pelacak Hilal

Teleskop dapat membidik dan mengunci posisi hilal secara otomatis dari input ephemeris tanpa memerlukan intervensi manual.

ESP32 Dual-Core RTOS

Core 0 didedikasikan untuk komputasi timing pulsa stepper presisi via AccelStepper, sementara Core 1 menangani stack jaringan WiFi, WebSocket, dan parsing telemetri NMEA.

Sensor Bosch BNO055 9-DOF

Sensor fusi cerdas menggabungkan akselerometer, giroskop, dan magnetometer untuk kalibrasi kemiringan (*tilt*) dan orientasi kutub utara otomatis. Data kalibrasi tersimpan permanen di NVS Flash.

GPS NEO-6M & Jam Atom UTC

Deteksi koordinat lintang/bujur toposentrik lokasi rukyat dan sinkronisasi waktu atom UTC secara mandiri di lapangan tanpa ketergantungan koneksi internet seluler.

Windows Standalone Edition

HILTRON Desktop v1.2.0

Aplikasi Windows mandiri berbasis PyWebView dengan server FastAPI dan kernel DE421 terbenam (embedded) secara utuh.

  • 100% Offline: Hisab ephemeris berjalan tanpa koneksi internet.
  • Koneksi WebSocket LAN langsung ke ESP32 dengan latensi < 5ms.
  • Konfigurasi Windows Firewall otomatis saat instalasi Inno Setup.
  • Performa GPU maksimal untuk simulasi skydome 3D.

Alur Pengamatan

3 Langkah Melacak Hilal

Dirancang ergonomis untuk mempermudah praktisi falak, tim rukyat, dan peneliti astronomi.

01

Tentukan Lokasi & Waktu

Gunakan tombol GPS otomatis atau cari koordinat lokasi titik rukyat Anda di seluruh Indonesia maupun dunia.

02

Amati Visibilitas 3D

Buka Skydome Ufuk Barat untuk melihat simulasi visual posisi hilal, sudut elongasi, tinggi mar'i, dan status MABIMS saat matahari terbenam.

03

Kunci & Lacak Teleskop

Hubungkan ESP32 Tracker melalui WiFi atau Cloud MQTT, klik Kunci Posisi Hilal, dan biarkan teleskop membidik serta mengimbangi rotasi bumi secara presisi.
